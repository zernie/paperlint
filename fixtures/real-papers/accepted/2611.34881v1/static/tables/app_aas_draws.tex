\subsection{Variability of the AAS Rows over Training Runs}
\label{app:aas_draws}

\noindent Tabs.~\ref{tab:codino_main} to~\ref{tab:dinov3_main} show one training run per AAS row. Grounding DINO has two draws per row: the late stage (epochs 9 to 12) run twice from the same epoch-8 checkpoint without a fixed seed. DINOv3 has four seeds ($42$ to $45$), each a separate run from the pretrained backbone. Tab.~\ref{tab:app_aas_draws} gives the mean and standard deviation over the runs of each row. The control rows of the tables are single runs.
