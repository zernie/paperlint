
\section*{Open Science}
We make the artifacts required to evaluate our contributions available at this link: \url{https://zenodo.org/records/20534406}.
These artifacts include the implementation of the iFinder framework, the curated dataset of publicly reported iTrue vulnerabilities used as ground truth, and scripts and configuration files necessary to reproduce the main experimental results in controlled environments. Beyond the reproducibility artifacts, we also maintain a public website at \url{https://linziyuu.github.io/iFinder-Website/} that compiles all 84 findings.
To prevent misuse prior to widespread patch adoption, we do not release exploit-grade proof-of-concept code for newly discovered vulnerabilities. The released artifacts are sufficient to reproduce our evaluation and validate the reported findings.
