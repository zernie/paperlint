An example of WHAT a findings table looks like — not itself a finding:

```markdown
| # | what | where |
|---|---|---|
| 1 | example | §1 |
| 2 | example | §2 |
| 3 | example | §3 |
```

There must be no analysis of causes here: this describes the format, it is not a report.
