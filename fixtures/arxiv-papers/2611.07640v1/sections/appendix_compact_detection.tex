\section{Detection and Controlled Expansion}
\label{app:detection}

Two detection measures appear in this paper. The \emph{offline probe} is a
DRIFT-style detector run on each passage outside any agent run; the \emph{runtime}
measure counts runs in which DRIFT's injection isolator partially or
completely removed the planted content. Table \ref{tab:detection-conditions}
uses the carrier-only offline probe, against which the detection-optimized
rewrites were optimized; the figures use the runtime measure.

Table \ref{tab:detection-conditions} gives offline detection and residual
ASR under DRIFT-isolation for each functional target and text condition:
regular, detection-optimized, and with plain or detection-optimized support
text. Figure \ref{fig:detectability-all-models} repeats
Figure \ref{fig:detectability-tradeoff} for each of the four models.
