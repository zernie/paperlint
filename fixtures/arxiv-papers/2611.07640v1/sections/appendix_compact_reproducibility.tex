The carrier-only detection probe uses DeepSeek V3.2
(\texttt{deepseek.v3.2}) at temperature 0. Trajectory annotation uses Claude
Opus 4.6 (\texttt{global.anthropic.claude-opus-4-6-v1}) at temperature 0.

Each run is a single episode of a ReAct-style tool-calling agent
(Table \ref{tab:run-config}). The episode ends when the model replies without
a tool call or reaches 500 messages. Every
run starts from a fresh copy of the environment's sandbox, and every
configuration runs once.
The agent receives no environment system prompt. Without a prompt defense it
has no system message at all; Spotlight and the two trust-hierarchy prompts
supply one; the trust-hierarchy prompts are in
Appendix \ref{app:trust-hierarchy}.
