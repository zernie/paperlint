\section{Environments}
\label{app:environments}

The benchmark has three environments (Table \ref{tab:environments}), with
25 agent-facing tools and
91 actions in total. Each environment is one shared sandbox: a set
of records that the environment's tools read and write. Every run starts from a fresh copy of the same template, so all cases
in an environment see the same world. A case varies only the user request,
the content planted in that world, and the checks that score the run.

Planted content enters through named placeholders in the sandbox records.
Before the agent starts, the harness fills the case's placeholder with the
instance's injection text. Every other placeholder is left empty, so the
surrounding records are identical across cases and instances. The harness
invokes \texttt{configure\_injections} and \texttt{sandbox\_reset} internally to plant content
and restore the sandbox; these setup operations are not exposed as tools to
the agent or the defenses.
