\section{Uncertainty and Case Composition}
\label{app:uncertainty}

\subsection{Case-bootstrap intervals}

Each model--defense configuration runs once per instance, so we estimate
uncertainty by resampling cases rather than runs. A bootstrap draw samples the
90 retained cases with replacement and keeps every
instance of each drawn case together. For each draw and table entry, we recompute the
rate separately for each model and then take the unweighted mean across models,
as in Table \ref{tab:defense-overview}. Intervals are the 2.5th and 97.5th
percentiles of 10000 draws. All metrics, targets, and defenses
share the same draws, so a difference between two cells is a paired estimate.
Table \ref{tab:headline-ci} gives the intervals of the headline metrics and
of each defense's ASR difference from no defense;
Table \ref{tab:target-ci} gives the intervals of ASR by functional target and
of each target's difference from \(b(U)\).

\ref{tab:case-coverage} and \ref{tab:same-budget} count cases instead: a
case is broken for a model if at least one of that model's attacked runs
succeeds. Table \ref{tab:case-coverage} counts the cases broken by \(b(U)\)
instances, by instances of the other targets, and by the other targets only.
The two sides have different budgets, since a case has more instances of the
other targets than of \(b(U)\). Table \ref{tab:same-budget} gives both sides the
same number of attacks per case.
