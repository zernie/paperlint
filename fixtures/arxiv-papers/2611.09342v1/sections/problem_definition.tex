\section{Problem Formulation}
Let $D = \{w_l\}_{l=1}^{L}$ be a document with $L$ words and a set of entities $\mathcal{E}_D = \{e_i\}_{i=1}^{|\mathcal{E}_D|}$. Each entity $e_i$ has a set of mentions $\mathcal{M}_{e_i} = \{m^i_j\}_{j=1}^{|\mathcal{M}_{e_i}|}$, i.e., phrases referring to the same entity. In the DocRE task, the goal is to predict a subset of relations from a predefined set $\mathcal{R} = \{r_k\}_{k=1}^{|\mathcal{R}|}$ that hold between entity pairs $(e_h, e_t)$, where $h \neq t$. For brevity, we denote such pairs as $(h, t)$. A relation $r \in \mathcal{R}$ is considered present between $e_h$ and $e_t$ if it is expressed between any of their mentions; these are labelled as positive pairs. If no relation exists between any mention pair, the entity pair is labelled {\tt NA} (i.e., negative) relation. Note that positive pairs may express multiple relations in $\mathcal{R}$.
