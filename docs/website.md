# Website

The project's domain is **[paperlint.dev](https://paperlint.dev)**, registered in November 2026
through Vercel. No site is deployed on it yet: the first version is
[#342](https://github.com/zernie/paperlint/issues/342).

- `.dev` is on the HSTS preload list, so browsers only open it over HTTPS: the site needs a
  certificate from its first deploy.
- Until the site exists, the npm page links to the GitHub README: `package.json` sets no
  `homepage`, only `repository`.
