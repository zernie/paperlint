# imports it. rebiber 1.4 moved to bibtexparser 2 (`bibtexparser>=2,<3` in its pyproject), and

# 🔴 aclpubcheck IS INSTALLED SEPARATELY, WITH `--no-deps`, BY ensure-checkers.sh, AND IT IS
# DELIBERATELY NOT LISTED HERE (a requirements file cannot say `--no-deps` for one line).
# It comes from its GitHub source pinned to a commit, not from PyPI: upstream says to install "from
# the GitHub repository (DIFFERENT from `pypi`)", and PyPI's 0.2.0 is a snapshot of 2022-10-10. The
# pin is 237bee3 of 2026-09-11, whose own setup.py pins rebiber to the SAME commit as below —
# measured 2026-09-27: both resolve together, `pip check` names no rebiber conflict.
# Why `--no-deps`: it still declares `tsv`, which has NO PREBUILT WHEEL AT ALL
# (`pip download --only-binary :all: tsv` → "from versions: none"), and whose source does not build
# under a modern setuptools:
#     AttributeError: install_layout. Did you mean: 'install_platlib'?
# That one line alone once made installing the WHOLE file fail, and that's why a paper went a month
# without an official format check.
# Verified, not assumed, on the pinned commit: `tsv` is imported NOWHERE in aclpubcheck's source,
# and neither is `setuptools`, which it also declares.
# So what follows is aclpubcheck's OWN dependencies, from its setup.py, minus tsv and setuptools. A list, rather than `aclpubcheck` on one line, so the next unrepresentable dependency
# reads as a missing line rather than an unverified assumption.
# 🔴 THE UPPER BOUNDS ARE REMOVED, AND THAT IS A MEASUREMENT, NOT CARELESSNESS. The first edition
# of this list copied aclpubcheck's bounds verbatim — and turned red on CI, where Python is newer:
#     ERROR: Could not find a version that satisfies the requirement pandas<2.0.0,>=1.5.0
#            (from versions: 2.1.1, 2.1.2, … 3.0.5)
# In other words, the package's upper bound had gone stale: pandas 1.x is not published for that
# interpreter at all. Verified by running against a REAL PDF (aisec-2026/paper.pdf) on numpy 2.4.6
# + pandas 3.0.5: the checker ran and reported 9 format findings (A4, font). The lower bounds stay
# — they rule out things that are known to be too old; there are no upper bounds because none of
# them has been verified, and an unverified bound breaks the install exactly when the environment
# gets updated.
# ⚠️ `--help` is NOT proof of anything: it prints usage and exits zero even when pandas cannot be
# imported in that same interpreter. Verified 09-17, caught the hard way.
