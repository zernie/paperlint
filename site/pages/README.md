# pages/

Empty on purpose. Next.js treats a `src/pages/` folder as its Pages Router unless a `pages/` folder exists at the project's root; Feature-Sliced Design's `pages` layer lives in `src/pages/`, so this folder keeps Next from reading it ([FSD with Next.js](https://feature-sliced.design/docs/guides/tech/with-nextjs)). The routes are in `app/`.
